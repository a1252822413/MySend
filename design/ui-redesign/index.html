Kuai · HarmonyOS UI / Rebuild 03

卡片分层次，数字说话

上一版用发丝线分层，读起来太平。这一版把每个可操作单元做成实体卡片： 背景差 + 圆角 + 轻投影建立层级，卡片内部才用线做分隔。 仪表感保留在读数上——设备名、速度、指纹、大小，全部等宽对齐。 暗色与亮色是两套独立调校，不是简单反色。

方向
工业实用 + 卡片层级 — 卡片承载信息，线只做组内分隔
层级
背景差 / 18px 圆角 / 轻投影 — 暗色靠内侧高光，亮色靠柔和投影
强调
暗 #3BE49A / 亮 #0B8F5B — 亮底绿色必须压深才够读
记忆点
接收时的同心波束 + 48px 速度读数 — 像示波器，不像进度条
