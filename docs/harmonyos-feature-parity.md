## 手机端额外增强（PC 端没有，但值回票价）

1. **系统分享面板接入**：在相册/文件管理器里选中文件 → 分享 → 「快传」，直接进入发送页并预填文件。这是手机端最高频的入口，成本低、收益大。
2. **通知栏进度 + 完成通知**：接收完成点通知可直接打开文件。
3. **扫码配对（可选，二期）**：对方屏幕显示二维码，扫码直达发送，绕开 AP 隔离导致的组播失败。
4. **省电策略提示**：检测到系统把应用加入"受限"名单时，引导用户设为「允许后台活动」。

## 限制说明（对应上表的 ⚠️）

**§限制1：剪贴板文件**
鸿蒙剪贴板（`@ohos.pasteboard`）支持文本、图片、URI，但"从系统文件管理器复制的文件"能否完整取出需要实测。
结论：**先做文本粘贴**（PC 端「发送文字」功能完整保留），文件粘贴列为待验证项，跑不通就不做。

**§限制2：保存目录**
手机分区存储下，三方应用不能任意写公共目录：
- 沙箱：随便写，但用户看不见 → 需要「导出」
- 相册（`PhotoAccessHelper`）：可写图片/视频，**文档类不行**
- 自选目录（`file.picker` + 持久授权）：可写任意类型，但需要用户首次授权

方案：默认沙箱 → 接收完成通知提供「保存到相册（媒体）/ 另存到…（文档）」，并在设置里允许把"自选目录"设为默认。
