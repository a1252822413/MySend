# 快传 · 界面重构 03（卡片层级 + 双主题）

## 这一版改了什么

上一版（02）用**发丝线**做分层：设备行、文件行、历史条目全是 1px 线分隔。问题是整页读起来"平"，
所有内容都在同一个平面上，扫视时找不到落点。

03 版把每个可操作单元做成**实体卡片**：

| 项 | 02（线分层） | 03（卡片分层） |
|---|---|---|
| 设备 | 行 + 上下线 | 独立卡片，圆角 18，悬停上浮 2px |
| 文件 | 行 + 上下线 | 卡片，左侧扩展名方块（EXE/JPG/PDF） |
| 历史 | 时间轴线 + 节点 | 卡片，左侧 3px 类型色条 |
| 设置 | 分组 + 行线 | 卡片组，卡内才用线分隔 |
| 层级手段 | 线条 | 背景色差 + 圆角 + 主题化阴影 |
| 底部 Tab | 顶边 2px 线 | 选中项做成浅绿小卡 |

仪表感没有丢：设备名、IP、指纹、大小、速度依然全部等宽对齐，强调色依然只有一处。

## 双主题

**不是简单反色**，两套的层级手段不同：

| 令牌 | Dark | Light |
|---|---|---|
| 屏底 | `#0A0E0C` | `#F0F3F1` |
| 卡片 | `#151F1B` | `#FFFFFF` |
| 卡内块 | `#1B2622` | `#F1F5F3` |
| 主文字 | `#E9F1EE`（15:1） | `#0F1614`（16:1） |
| 次要文字 | `#9AA8A3`（6.9:1） | `#55635C`（7.1:1） |
| 微型标签 | `#7B8A84`（4.7:1） | `#6B7A72`（4.8:1） |
| 强调 | `#3BE49A` | `#0A8255`（白字 4.7:1） |
| 强调文字 | 同 `#3BE49A` | `#07714A`（6.2:1） |
| 卡片阴影 | 内侧高光 + 深投影 | 双层柔和投影 |
| 遮罩 | `rgba(4,7,6,.62)` | `rgba(15,22,19,.30)` |

亮色的关键决策：**绿色必须压深**。`#3BE49A` 放在白底上做小字只有 1.9:1，完全不可读，
所以亮色主题把绿色拆成两个用途——图形用 `--accent`（#0A8255），文字用 `--accent-ink`（#07714A）。

切换方式：页面右上角 Dark / Light，写进 `localStorage`，刷新保留。

## 六个屏

| # | 屏幕 | 卡片结构 |
|---|---|---|
| 01 | 接收 | 本机大卡（含信号环 + 指纹）+ 2 张设备卡 + 1 张网络卡 |
| 02 | 发送 | 目标区（无卡）+ 3 张文件卡 + 底部「总量卡 + 发送」 |
| 03 | 接收确认 | 磨砂遮罩 + 悬浮 sheet（22px 圆角），内部文件卡用卡内块色 |
| 04 | 传输中 | 无卡片背景的波束区 + 底部信息卡（进度条 / 目标 / 落盘路径） |
| 05 | 历史 | 4 张日志卡，左侧类型色条区分收发 |
| 06 | 设置 | 4 组卡片，路径用终端风格内嵌块 |

## 令牌

`styles/tokens.css`。结构：

```
:root, [data-theme="dark"] { ... }   /* 暗色是主场景 */
[data-theme="light"] { ... }          /* 亮色独立调校 */
:root { 字体 / 字阶 / 间距 / 圆角 / 动效 / 尺寸 }
```

组件里没有硬编码颜色，只有 `var(--*)`。

## 动效

- 入场：`IntersectionObserver` + 80ms 错峰，只动 `opacity` / `translateY(22px)`。
- 卡片悬停：`translateY(-2px)` + 阴影升级，160ms。
- 常驻动效仅两处：信号环脉冲、波束脉冲（`scale`，不触发布局）。
- `prefers-reduced-motion: reduce` 下全部关闭。

## 自检

| 关卡 | 结果 |
|---|---|
| 卡片层级是否成立 | 底 / 卡 / 卡内块 三级，暗亮两套都用背景差验证过 |
| 对比度 | 正文 15–16:1，次要 6.9–7.1:1，微型标签 4.7–4.8:1，白字按钮 4.7:1 |
| 触摸目标 | 卡片 60px+，按钮 44px，开关 40×22（外覆 46 高行） |
| 焦点可见 | `:focus-visible` 2px 强调色描边 + 2px 偏移 |
| 状态覆盖 | 卡片 hover / active / idle、开关开合、空态、模态、进度 |
| 双主题一致性 | 所有色值走令牌；亮色单独校验，不是反色 |
| 动效降级 | CSS + JS 双向关闭 |
| 响应式 | ≥1120 三列 / 更窄自动换行 / <460 单列 |

## 落地到 ArkUI

| Web | ArkUI |
|---|---|
| `.card` | `Column().backgroundColor(surface).borderRadius(18).border({width:1,color:cardBorder}).shadow({radius:24,color:shadow,offsetY:10})` |
| 双主题 | `common/Theme.ets` 导出两套 token 对象，用 `AppStorage` 存 `themeMode`，组件读 `@StorageProp` |
| 卡片悬停 | ArkUI 无 hover 语义（触屏），改用 `onTouch` 按下时 `scale(0.98)` |
| `backdrop-filter` | 用半透明 `backgroundColor` 近似 |
| 波束脉冲 | `Stack` + 3 个 `Circle`，`animateTo` 循环改 `scale`/`opacity` |

> ArkUI 的 `shadow` 只支持单个阴影，暗色下的"内高光"要用一个 1px 的顶部描边叠加模拟
> （`Row().height(1).backgroundColor('rgba(255,255,255,0.05)')` 放在卡片顶部）。
