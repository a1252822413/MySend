Kuai · HarmonyOS UI / Rebuild 02

把传输做成仪表，
而不是一张表单

快传的核心不是「填设备、选文件、点发送」，而是此刻链路有多快、对端是谁、文件落在哪。 所以整套界面按工业仪表的逻辑重建：等宽数字承担全部读数，发丝线划分层级， 信号绿只留给「在线 / 接收 / 主操作」这一件事。

方向
工业实用 — 仪表盘密度、等宽数字、发丝边框
展示字
JetBrains Mono — 承担所有数字与标签
正文字
Noto Sans SC — 900 字重做中文标题，负字距
主色
#3BE49A — 唯一强调色，仅 10% 面积
记忆点
接收时的同心波束 + 56px 速度读数 — 像示波器，不像进度条
